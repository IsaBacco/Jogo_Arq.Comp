

1. **Pergunta:** Qual componente é conhecido como o "cérebro" do computador, responsável por executar as instruções dos programas e coordenar o sistema?
   * **Resposta de memorização:** **CPU**

2. **Pergunta:** Qual unidade interna do processador realiza exclusivamente cálculos matemáticos (como adição) e comparações lógicas (como E/OU)?
   * **Resposta de memorização:** **ULA** (Unidade Lógica e Aritmética)

3. **Pergunta:** Qual estrutura do processador busca e decodifica as instruções na memória, gerando os sinais que controlam os demais componentes?
   * **Resposta de memorização:** **UC** (Unidade de Controle)

4. **Pergunta:** Como são chamadas as pequenas posições de memória de altíssima velocidade localizadas dentro do próprio processador para guardar dados imediatos?
   * **Resposta de memorização:** **Registradores**

5. **Pergunta:** Qual é a memória principal, volátil, que armazena temporariamente os dados dos programas em execução enquanto o computador está ligado?
   * **Resposta de memorização:** **RAM**

6. **Pergunta:** Qual memória não volátil vem gravada com instruções permanentes (como o firmware/BIOS) essenciais para a inicialização do computador?
   * **Resposta de memorização:** **ROM**

7. **Pergunta:** Qual tipo de memória não volátil permite que seu conteúdo seja apagado e reprogramado eletricamente sem precisar ser removida da placa?
   * **Resposta de memorização:** **EEPROM**

8. **Pergunta:** Qual tecnologia de memória não volátil (derivada da EEPROM) apaga e grava dados em blocos rapidamente, sendo a base de SSDs e pendrives?
   * **Resposta de memorização:** **Flash**

9. **Pergunta:** Qual memória estática ultrarrápida fica posicionada entre a CPU e a RAM para armazenar cópias dos dados mais acessados e evitar esperas do processador?
   * **Resposta de memorização:** **Cache**

10. **Pergunta:** Qual termo define os dispositivos de armazenamento permanente (como HDs e SSDs) usados para guardar grandes volumes de arquivos?
    * **Resposta de memorização:** **Memória de massa (armazenamento)**

11. **Pergunta:** Qual recurso permite que os periféricos transfiram dados diretamente para a memória RAM sem precisar sobrecarregar a CPU?
    * **Resposta de memorização:** **DMA** (Direct Memory Access)

12. **Pergunta:** Qual barramento unidirecional transporta a localização de memória que a CPU deseja acessar?
    * **Resposta de memorização:** **Address bus** (Barramento de endereço)

13. **Pergunta:** Qual barramento bidirecional é responsável por carregar os dados reais lidos ou gravados entre a CPU e os demais componentes?
    * **Resposta de memorização:** **Data bus** (Barramento de dados)

14. **Pergunta:** Qual chip integrado contém CPU, memória (RAM/Flash) e portas de entrada/saída no mesmo componente, sendo muito usado em automação e robótica?
    * **Resposta de memorização:** **Microcontrolador**

15. **Pergunta:** Como é chamado o processador que possui dois núcleos físicos de processamento independentes no mesmo chip?
    * **Resposta de memorização:** **Dual core**

16. **Pergunta:** Como é classificado o processador que conta com quatro núcleos físicos de processamento para maior desempenho multitarefa?
    * **Resposta de memorização:** **Quad core**
